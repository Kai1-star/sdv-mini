# sdv-mini 基于Rust开发 

## 介绍 
两块 micro:bit v2 当 ECU，通过**真实 CAN 总线**（MCP2515 + SN65HVD230）通信，Mac 上用 Rust 写的 `can-tool` 充当简化版 CANoe，**全部用 Rust**。目标是把 ISO 26262 的 Freedom from Interference 从概念变成能当场演示的现象。
